# aviralsaxena.me — Portfolio

**Live:** [aviralsaxena.me](https://aviralsaxena.me)

This is the portfolio of **Aviral Saxena**, Full-Stack Developer & AI Engineer. An interactive experience inspired by 90s skate zine aesthetics: custom 2D skater rig, scroll-driven physics, skate decks flipping to reveal projects, wheel durometer ratings for technical stack, and a card binder for verified credentials.

## Sections
- **Hero**: Skater rolls in, spelling out AVIRAL SAXENA across the course.
- **Experience (Run Log)**: Internships and experience at Miebach Consulting, Mahamela Innovations, and ISTE, alongside academic credentials from SRM IST.
- **Projects (The Decks)**: Interactive skate decks including DashCart, Snipify, aviralsaxena.me, Warehouse AI, and DevPulse.
- **Stack (Wheels)**: Durometer-rated skills across AI & Agents, Backend & Data, Frontend, and DevOps & Cloud.
- **Certifications (Card Binder)**: Interactive trading card binder featuring Oracle Agentic AI, TCS iON AI Foundation, Google Cloud Computing, and NPTEL Distributed Systems.
- **Contact (Finish Line)**: Direct messaging form, links to GitHub, LinkedIn, LeetCode, and Résumé.

## Tech Stack
- Next.js (Static Export)
- TypeScript
- Lenis Smooth Scroll
- Custom 2D Rig & Math Engine
- Tailwind CSS & CSS Modules
